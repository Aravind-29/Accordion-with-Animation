# Accordion with Hover Effects and Animation
This project demonstrates how to implement animations and interactivity using JavaScript and CSS. The web app features a modern accordion component with hover effects, smooth transitions, and interactive behavior.

## Features
 1. **Accordion Component** 
- Each section expands/collapses on click.
- Only one section remains open at a time.
- Smooth animations for opening and closing sections.
2. **Interactive Animations**
- Header hover effect for better user experience.
- Content fades and slides into view when expanded.
- Rotate icon indicator (▼) for open/close states.
## Technologies Used
- HTML: Structure of the accordion.
- CSS: Styling and animations.
- JavaScript: Adding interactivity.

## Installation and Usage
1. Clone the repository or copy the files into your project folder.

2. Open the ```index.html``` file in any web browser.

3. Interact with the accordion:

- Click on a section header to expand/collapse its content.
- Observe the animations and transitions.
